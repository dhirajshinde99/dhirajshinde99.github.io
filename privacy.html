Privacy policy

GiggleGlow Uploader · Effective 10 October 2026

Who uses this app

GiggleGlow Uploader is a private tool used only by the owner of the GiggleGlow TV YouTube channel to manage that channel. It is not offered to other people.

What the app accesses, with the owner's permission

  • YouTube: to upload the owner's videos to the owner's channel, set their thumbnails, add them to the channel's playlists, and check whether a scheduled video has been published.
  • Google Drive: to read the video and image files the owner places in the app's folders, and to create the app's own folders, prompt documents and report files.
  • Gmail: only to send emails from the owner's account to the owner (daily prompts and reports). The app does not read the owner's email.

How the information is used

The information is used only to perform the tasks above for the owner. It is not used for advertising, profiling or analytics, it is not sold, and it is not shared with anyone.

GiggleGlow Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

The owner's sign-in token is stored as an encrypted secret in the owner's private GitHub repository. Video and image files are processed temporarily on the automation server and deleted when each run ends. The app keeps a small log of which episodes were uploaded (episode numbers, YouTube video IDs and dates) in the owner's private repository.

YouTube API Services

This app uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Removing access

The owner can remove the app's access at any time from their Google Account at myaccount.google.com/permissions. Deleting the app's GitHub repository deletes the stored token and logs.

Children

The app is used only by its adult owner and does not collect information from children. Videos it publishes are marked "made for kids" on YouTube, and YouTube handles viewer information under its own policies.

Changes

Any changes to this policy will be posted on this page with a new effective date.
